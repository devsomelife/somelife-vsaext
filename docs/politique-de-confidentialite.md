# Politique de confidentialité

VSA Ext est une extension Chrome qui aide à remplir sa propre feuille de temps VSA. Elle ne collecte, n'envoie et ne vend aucune donnée.

## Données lues

- Les noms des clients et des projets affichés dans les listes déroulantes de votre propre page de saisie VSA, pour que vous puissiez les choisir dans l'extension.
- La langue de cette page.

L'extension ne fonctionne que sur l'adresse VSA que vous saisissez vous-même.

## Données enregistrées

Enregistrées uniquement dans votre navigateur, sur cet ordinateur (`chrome.storage.local`) :

- Les journées et les notes que vous saisissez.
- La liste des clients et des projets lue dans VSA.
- Vos réglages : adresse VSA, langue, nom de l'onglet CRA et adresse du classeur CRA.

## Données partagées

- Rien n'est envoyé au développeur ni à un tiers. Il n'y a ni serveur, ni statistiques, ni suivi.
- Pour remplir votre feuille de temps, l'extension utilise votre page VSA comme vous le feriez à la main : les requêtes partent uniquement vers votre propre site VSA.
- Les données ne sortent de l'extension que si vous le décidez : `Copy for CRA sheet` copie le mois dans le presse-papiers, et `Export JSON` ou `Export CSV` enregistre un fichier.

## Autorisations

- `storage` : conserve vos données dans le navigateur.
- `scripting` : fait fonctionner l'extension sur votre page VSA uniquement.
- Accès au site : demandé pour la seule adresse VSA que vous saisissez, jamais pour d'autres sites.

## Suppression des données

- Supprimez des lignes, ou utilisez `Reset catalog`, dans l'extension.
- Désinstaller l'extension efface toutes ses données.
